<h2 id="what-the-sdi-is-and-why-it-is-mandatory">What the SdI is and why it is mandatory</h2><p>The Sistema di Interscambio (SdI) is the Revenue Agency platform through which all electronic invoices issued in Italy since 2019 must pass, in FatturaPA XML format. If an invoice does not pass through the SdI, or is rejected by the system, it is treated for tax purposes as not issued: creating the document is not enough, it must have been accepted by the System. Since 2024 the obligation also covers flat-rate taxpayers, after a transitional period linked to the revenue threshold.</p><h2 id="what-happens-when-you-send-an-invoice">What happens when you send an invoice</h2><p>The XML file is transmitted to the SdI through one of the enabled channels (PEC, web service, FTP, or directly from the Invoices and Receipts portal). The System runs over 50 automatic checks on the file: format, personal data, VAT number, tax code, progressive numbering, amounts, withholdings, validity of the digital signature if present. The System has a maximum of 5 days to complete these checks. If the invoice passes the checks, it is forwarded to the recipient; if it does not, it is rejected and a rejection receipt with a numerical code and a short description of the reason is sent to the sender.</p><h2 id="what-to-do-in-case-of-rejection">What to do in case of rejection</h2><p>A rejected invoice has never been issued for tax purposes: it must be corrected and resubmitted, not simply filed away as if the problem were over. The rules give 5 days to correct and resubmit the rejected invoice while keeping the original issue date. The rejection code received (format 0XXXX) indicates the specific cause: missing data, invalid format, inconsistency between fields. The Revenue Agency provides a free online validator to check the XML file is correct before the official submission, useful to prevent recurring rejections for the same errors.</p><h2 id="technical-specifications-change-over-time">Technical specifications change over time</h2><p>The e-invoice XML schema is not static: it is updated periodically with new versions of the technical specifications, and invoices sent with an outdated version are automatically rejected from the moment the new version comes into force. Those using up-to-date management software do not need to worry about this directly, but those generating XML files with home-made or outdated tools risk systematic rejections until they align their system with the current version.</p><h2 id="active-24-hours-a-day-real-time-checks">Active 24 hours a day, real-time checks</h2><p>The Sistema di Interscambio operates 24 hours a day, seven days a week: invoices can be sent on Saturday, Sunday or public holidays, and checks are still carried out in real time with a delivery receipt or rejection notice returned within standard timeframes. This makes the SdI compatible with automated invoicing flows that generate documents outside office hours, with no need to manually supervise sending.</p><p><em>The technical rules for e-invoicing are subject to periodic updates: always check the version of the specifications in force with an accountant or your management software provider.</em></p>
